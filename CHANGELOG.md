## Версия от 12.11.2026

### Интерактивная карта травматологических пунктов (web/map.html, web/js/map.js, web/css/style.css)
- Интегрирован официальный картографический движок Яндекс.Карты JS API v2.1 с персональным API-ключом разработчика.
- Разработан региональный автопоиск через специализированный провайдер организаций (SearchControl yandex#search): поиск извлекает реальные медицинские учреждения, телефоны регистратур и график работы из Яндекс.Справочника.
- Реализовано обратное геокодирование координат пользователя для автоматического определения населенного пункта (город, район).
- Устранена привязка к Москве: при определении местоположения за пределами Московского региона московские центры исключаются из выдачи, а список и карта заполняются травмпунктами найденного города/региона.
- Добавлена возможность поиска по городам России через строку поиска по нажатию клавиши Enter с автоматическим перемещением карты и загрузкой местных отделений.
- Настроен немедленный запрос доступа к геолокации при открытии страницы с защитным тайм-аутом и расчетом расстояния по формуле гаверсинусов (Haversine formula).
- Добавлена специальная кнопка повторного запроса геопозиции («Определить снова») на случай случайного отклонения запроса или сбоя геолокации.
- Реализована двусторонняя синхронизация двухпанельного макета: клик по карточке центрирует карту и открывает информационный балун с действиями; клик по маркеру подсвечивает карточку и прокручивает список.
- Для каждого учреждения добавлены быстрые целевые действия: прямой звонок в регистратуру (протокол tel:) с отображением номера и построение автомобильного маршрута в Яндекс.Картах / Навигаторе.
- Внедрен механизм Graceful Degradation: при отсутствии связи с API-сервером или превышении лимитов отображается предупреждение, а интерактивный список отделений с телефонами и адресами сохраняет 100% работоспособность.
- Сохранены адаптивные мобильные вкладки («Список отделений» / «Интерактивная карта») с автоматическим пересчетом вьюпорта карты при переключении.
